# Kirov Threat SDK

> Python SDK for integrating with the Kirov security reconnaissance ecosystem.

## Installation

```bash
pip install kirov-threat-sdk
```

## Usage

```python
from kirov_threat_sdk import Scanner

scanner = Scanner(api_key="your-api-key")
results = scanner.scan("example.com")
print(results)
```
